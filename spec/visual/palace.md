# Create an Immersive 3D Floating Palace — Single HTML Experience

Act as a senior creative developer, Three.js specialist, 3D environment artist, and award-winning interactive web designer.

Your task is to create a visually breathtaking, fully interactive 3D experience called **THE FLOATING PALACE**.

The experience should look like a premium real-time 3D environment from a high-end video game, not a conventional website.

## 1. Technical requirements

- Deliver everything in ONE standalone `index.html` file.
- Use HTML, CSS, JavaScript and Three.js.
- Load Three.js through a CDN.
- No React, Vue, build tools, npm, or separate local files.
- All CSS and JavaScript must be embedded in the HTML.
- The file must run directly in a modern browser.
- Use procedural geometry and materials instead of static screenshots or pre-rendered images.
- Write clean, organized, production-quality code.

## 2. The 3D environment

Create a gigantic magical palace floating above an endless sea of clouds.

The architecture should include:

- An enormous central palace with multiple towers.
- Elegant golden domes and ornamental spires.
- Floating architectural platforms and islands.
- Marble bridges connecting different structures.
- Glowing waterfalls flowing from the floating islands.
- Suspended gardens with trees and vegetation.
- Intricate architectural details and decorative elements.
- A majestic staircase leading to the main entrance.
- Floating rocks and smaller islands surrounding the palace.

The palace should feel monumental, believable, and visually rich.

## 3. Environment and atmosphere

Create a cinematic fantasy atmosphere:

- Beautiful volumetric-looking clouds.
- Atmospheric fog and depth.
- A dramatic sunset with golden sunlight.
- Soft god rays or simulated light shafts.
- Realistic water reflections where possible.
- Glowing particles floating through the atmosphere.
- Birds flying around the palace.
- Subtle environmental animation.
- A beautiful sky gradient with atmospheric depth.

## 4. Camera and interaction

Implement a fully interactive 3D camera.

Required controls:

- Drag to rotate around the palace.
- Scroll to zoom in and out.
- Smooth camera movement.
- Damping and inertia.
- Restrict camera movement to prevent disorientation.
- Support mobile touch gestures.

Add a cinematic automatic camera mode that slowly orbits the palace.

Include a button to switch between cinematic mode and manual exploration.

## 5. Interactive features

Make the environment feel alive.

Include:

- Animated waterfalls.
- Moving clouds.
- Floating particles.
- Animated birds.
- Subtle movement in vegetation.

## 7. Rendering quality

Prioritize visual quality:

- Antialiasing.
- Physically based materials.
- High-quality lighting.
- Ambient occlusion approximation.
- Shadows.
- Tone mapping.
- Bloom or glow effects.
- Depth and atmospheric perspective.

Optimize rendering for desktop and mobile.

- Use instanced geometry for repeated objects.
- Avoid unnecessarily expensive rendering operations.
- Handle browser resizing.
- Handle WebGL initialization failures gracefully.
- Prevent memory leaks.
- Avoid console errors.
- Include a fallback message if WebGL is unavailable.
